⭐ Important Questions

How should I use these notes?

Read the chapter notes first, then revise the important questions before your test.

Can I add my own notes images?

Yes. Create an images folder in this repository and add your note photos there. Then use an image tag such as <img src="images/history-1.jpg">.

Can I add more chapters?

Yes. Copy a chapter card in the HTML and change its subject, title and notes.
